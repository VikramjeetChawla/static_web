Product Catalog API and its Swagger UI reference

A REST API for managing products in an online store, with filtering, sorting, and pagination. The reference lists every parameter, request body, response, and error code, and uses one error format across all endpoints. Readers can try each endpoint in the browser.

  • GET /api/products
  • GET /api/products/{id}
  • POST /api/products
  • PUT /api/products/{id}
  • DELETE /api/products/{id}

Built with Node.js and Express. Documented with Swagger UI and OpenAPI 3.0.
